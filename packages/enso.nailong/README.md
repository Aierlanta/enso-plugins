# 奶龙

奶龙主题。浅色是奶油底配巧克力棕字，深色是巧克力夜配奶龙黄。主题键是 `enso.nailong/nailong`。

需要 EnsoCode 0.3.3 以上：大部分奶龙图写在 `themes/nailong.json` 的 `assets` 素材槽位里，旧版本不认这个字段。白云、字标、好耶、奶酪斑点和气泡仍在 `themes/nailong.css`，安装或更新时要同意「修改界面样式」。`permissions` 是空数组。

## 界面上的奶龙

| 位置                                                 | 锚点                        | 素材                       |
| ---------------------------------------------------- | --------------------------- | -------------------------- |
| 主窗口画布的奶酪斑点                                 | `canvas`                    | 纯 CSS 圆点                |
| 侧栏底部躺在云上                                     | `sidebar`                   | 表情「躺平」动图、官网白云 |
| 输入框后面探头，聚焦时往上探；有待办条时改到待办条上 | `composer`、`todo`          | 表情「晚安」第一帧         |
| 新对话没有消息时「热烈欢迎」                         | `timeline`                  | 表情「热烈欢迎」动图       |
| 没打开对话时挥手，下面是字标                         | `main`                      | 官网 3D 形象、官网字标     |
| 用户消息奶黄气泡                                     | `message-user`              | 纯 CSS                     |
| 思考块前「在忙」                                     | `thinking`                  | 表情「在忙」动图           |
| 代码块上沿探出小脸，状态行左边的小脸                 | `code-block`、`status-line` | 官网 Q 版探头              |
| 时间线里的待办「好耶」                               | `todo`                      | 表情「好耶」动图           |
| 右侧面板角落暴暴龙戴耳机敲键盘                       | `side-panel`                | 暴暴龙表情动图             |

系统开了「减少动态效果」时，动图换成第一帧，探头不再跳。
