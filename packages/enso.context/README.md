# Context Window

在侧栏查看当前会话的上下文窗口：已用多少、各部分占比、压缩前还能发几次请求，以及提示词缓存命中率。

## 使用

打开侧栏「上下文」。当前会话发出第一条消息后开始显示，之后每 2 秒刷新。

## 功能

- 顶部显示「已用 / 窗口大小」和进度条，用到 70% 变为警告色，90% 起视为将满。
- 四项指标：
  - 提示词缓存：最近一次请求里缓存读取的占比。
  - 起步占用：系统提示词、工具定义、Skills、指令与记忆合计，每次请求都会带上。
  - 每次增长：相邻两次请求之间占用增加的中位数。
  - 还能容纳：按每次增长估算，压缩前还能发多少次请求。
- 方块图与分类列表：系统提示词、工具、Skills、指令与记忆、文件、工具结果、会话，各分类可展开查看条目，并显示剩余空间。

子 agent 的用量不计入。模型还没实报用量时显示估算值，并标注「估算值」。最近 30 个会话的数据保存在插件数据目录（`sessions.json`）。

## 权限

| 权限 | 用途 |
| --- | --- |
| `ui.view` | 打开侧栏页面 |
| `agent.observe` | 接收会话的 `context_usage` 事件来统计占用 |
