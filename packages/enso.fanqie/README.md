# 番茄小说 · EnsoCode 侧栏插件

在 EnsoCode 的侧栏里浏览、搜索和阅读番茄免费小说。

> **非官方项目，仅供学习与技术研究。** 使用前请先阅读文末的[免责声明](#免责声明)。

## 功能

- 书城推荐、搜索、分页加载
- 书籍详情：简介、字数、评分、在读人数，目录按卷分组，可倒序，读过的章节标灰
- 阅读器：按章阅读，自动预读下一章；字号、行距、黑体/宋体、背景（默认 / 纸张 / 护眼）可调，跟随深色模式
- 书架：在书籍详情里点「加入书架」收藏，读到哪里一目了然
- 阅读历史：自动记住每本书读到第几章、读到哪个位置，点一下接着读；多个面板之间同步进度
- 缓存管理：自动只保留最近 600 章正文和 300 张封面，历史页可一键清理

不需要登录。

| 快捷键 | 作用 |
| --- | --- |
| ← / → | 上一章、下一章 |
| 空格 / PageDown | 翻页，到底后进入下一章 |
| Esc | 关闭设置，或返回书籍详情 |

## 环境要求

- 带 Enso 插件系统的 EnsoCode 桌面版
- 封面是 HEIC 格式：macOS 上用系统自带的 `sips` 转码；其他系统装了 ffmpeg 会用它转，没装就不显示封面，不影响阅读

## 打开阅读器

1. 在 **设置 → 插件** 里安装并启用 **番茄小说**。
2. 打开任意会话，展开右侧面板，点 **新建标签页（+）**，选 **番茄小说**。

## 缓存与数据

插件数据在 EnsoCode 的插件数据目录里（macOS）：

```
~/Library/Application Support/enso-code/extension-plugins/data/enso.fanqie/
├── chapters/     已读正文，自动只保留 600 章
├── covers/       封面，自动只保留 300 张
├── shelf.json    书架、阅读历史与进度（最多 60 本，优先保留书架）
└── device.json   匿名设备身份
```

在 **历史** 页能看到当前占用，点两次 **清理缓存** 清空正文和封面，书架和历史不受影响。卸载插件时整个目录会一起删除。

## 实现说明

- 数据来自内置的 `openfanqie/`（MIT），以匿名设备身份访问番茄小说接口，正文在本机解密。
- 侧栏页面跑在沙盒 iframe 里，不能直接访问外网，所有请求都由插件后台进程完成；单次传给页面的数据有 64KB 上限，所以长目录和长章节都分块传输。
- 匿名设备用一阵后正文接口可能返回空响应，后台会自动换一台新设备重试一次。

| 文件 | 作用 |
| --- | --- |
| `enso-plugin.json` | 插件清单 |
| `main.mjs` | 后台进程：书城、搜索、目录、正文缓存、封面转码、书架、缓存管理 |
| `index.html` | 侧栏页面：书城、书架、详情、阅读器 |
| `openfanqie/` | 番茄小说接口签名、设备注册与正文解密 |

## 常见问题

**提示「请求太频繁」或某一章打不开**
服务端对匿名访问有频率限制，稍等一会儿点 **重试**。

**突然全部不能用了**
这是非官方接口，服务端随时可能调整。
