# Monokai Pro

Monokai Pro 风格的 EnsoCode 主题：深色炭黑画布 + 浅色暖白画布，强调色 `#ff6188`。

## 安装

- **市场**：设置 → 插件 → 市场，搜索 `Monokai Pro`。
- **本地目录**：设置 → 插件 → 安装目录，选中本文件夹；或：

```bash
enso-server plugin install .
enso-server plugin enable enso.monokaipro
```

然后在 **设置 → 外观 → 主题** 选择 `enso.monokaipro/monokaipro`。

## 调色板

| 字段 | 深色 | 浅色 |
| --- | --- | --- |
| canvas | `#221f22` | `#faf4f2` |
| surface | `#2d2a2e` | `#ffffff` |
| sunken | `#1e1b1e` | `#f3eeea` |
| accent | `#ff6188` | `#ff6188` |
