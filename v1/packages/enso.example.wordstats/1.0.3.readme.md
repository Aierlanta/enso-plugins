# Word Stats

统计项目里文本文件的字数、行数和高频词，结果以卡片展示。这是一个示例插件，演示 Agent 工具、工具卡片和插件自带的 Skill。插件没有侧栏页面。

## 使用

在会话里让 agent 统计某个文件，例如「统计 README.md 的字数」。agent 会调用 `count_words` 工具，结果显示为一张卡片，包含词数、行数、字符数和高频词条形图。

## 功能

- `count_words` 工具：
  - `path`：相对项目根目录的 UTF-8 文本文件路径，不能越出项目。
  - `top`：列出多少个高频词，1 到 20，默认 5。
  - 高频词不区分大小写，只统计至少 2 个字符的词。
- `bar-chart` Skill：agent 可以输出 `enso.example.wordstats:bars` 代码块，每行写一个 `标签: 数值`，界面会渲染成条形图。

## 权限

| 权限 | 用途 |
| --- | --- |
| `agent.tool` | 提供 `count_words` 工具 |
| `fs.read` | 读取项目目录（`.`）下的文件 |
| `ui.slot` | 渲染工具卡片和条形图代码块 |
